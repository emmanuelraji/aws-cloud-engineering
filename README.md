# ☁️ AWS Cloud Engineering Journey

Welcome to my **AWS Cloud Engineering Journey** repository!

This repository documents my progress toward becoming an **AWS Cloud Engineer** through hands-on practice, continuous learning, and real-world cloud projects.

My focus is on developing a strong foundation in cloud computing, Linux, networking, security, scripting, and infrastructure automation.

## 🎯 Learning Goals

- 🐧 **Linux Fundamentals** — Develop proficiency in Linux commands, file systems, permissions, and system administration.
- 🌐 **Networking** — Understand IP addressing, DNS, TCP/IP, subnets, routing, and firewalls.
- ☁️ **AWS Core Services** — Learn AWS services, cloud architecture, and infrastructure management.
- 🔐 **IAM & Cloud Security** — Practice identity and access management, permissions, and security best practices.
- 🐍 **Python & Bash** — Develop scripting skills to automate repetitive tasks.
- 🛠️ **Git & GitHub** — Track progress, manage code, and document projects.
- 🏗️ **Terraform & Infrastructure as Code** — Learn to provision and manage cloud infrastructure through automation.
- 🚀 **Hands-On Projects** — Build, document, and improve practical cloud engineering projects.

## 🗺️ Learning Roadmap

My learning journey is organized around these key areas:

1. Linux and networking fundamentals
2. AWS fundamentals and core services
3. Identity, access management, and cloud security
4. Python and Bash scripting
5. Git and version control
6. Infrastructure as Code with Terraform
7. Hands-on AWS cloud projects

## 📂 Repository Goals

## 📈 Progress & Commitment

I believe in learning by doing. My goal is to turn theoretical knowledge into practical skills by consistently building, testing, documenting, and improving cloud projects.
